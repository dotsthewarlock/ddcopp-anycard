Instructions

Step 1: Create the bookmarklet

Click the button below to copy the bookmarklet code. Create a bookmark in Chrome and paste the copied code into the URL field.

Step 2: Use the workflow

  1. Paste card + PIN data on the left.
  2. Click Generate Links.
  3. Click a generated card.
  4. The card/PIN is copied to clipboard.
  5. AnyCard opens in the popup window.
  6. Click your bookmarklet.
  7. The bookmarklet fills the fields and submits automatically.
